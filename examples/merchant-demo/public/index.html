Tonbankcard merchant-demo

Reference Express.js storefront that creates a sandbox invoice, embeds the @tonbankcard/merchant-sdk widget, and receives webhooks — entirely non-custodial.

Environment: TON testnet · public C3 sandbox. Need test TBC? Use the TBC faucet (1 dispense per address per hour).
